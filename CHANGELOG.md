# Changelog

## 0.1.0

- Start Bud as a Git manager, with an empty home screen and saved local repositories.
- Open existing repositories or clone into a new local folder.
- List local and remote branches and switch between local branches.
- Render a colourful, paged commit graph across all refs, including merge connections and detached HEAD history.
- Browse repositories in grid or list view, and select avatar colours when opening, creating, or cloning repositories.
- Store SSH key passwords in the system credential store, with support for replacing and removing saved passwords.
- Register existing SSH keys and choose a default or per-repository identity for clone, fetch, and push.
- Preserve shared controls, themes, typography, window behavior, shortcuts, and popup interactions, with green as the default accent.
